当前0.9.13自定义服务端在仅有单个检查客户端、同步模式为True时，未下发tick的0.1s间隙仍推进约12帧。它不满足固定时窗实验的时钟条件。完整实时P4与物理端导航归位不能声称通过验证，控制台设有启动前拒绝与驻车保护。验证期间CARLA进程退出，交付时没有运行中的CARLA服务；网页历史回放与本机资源监测可独立工作。

官方示例目录为0.9.16，原生扩展需要匹配服务端、解释器及其硬件/服务依赖；没有声称所有扩展已经运行。网页常用适配功能与本机原程序窗口是两种明确标注的入口。

## 2026-11-09 原生 RPC 闪退修复与部署

原版库的关闭失效套接字测试退出码134；修复版通过。修复版统一会话读写/关闭 strand，关闭操作幂等且使用 error_code。已重新链接 Shipping 二进制并生成匹配debug/sym，备份后部署到 runtime 和源码输出目录；地图资产未重打包。

隔离测试1800次短连接、60次合法RPC、181秒带相机运行均通过；实际入口已核对进程 SHA256，连续观测121秒，期间真实导航、复位及再次导航未闪退。空闲限帧实测29.97FPS，默认Low画质，独立用户配置不改全局配置。同步 benchmark 可加速仿真，不能把仿真帧数简单视为墙钟渲染帧率上限。长期GPU故障不能由短测排除。

僵尸进程过滤、子进程回收和独立0.5秒状态监测已验证；真实意外退出0.777秒恢复启动按钮。控制台30项测试通过。详见native-crash-fix.md。
