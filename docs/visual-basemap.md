# HAUT 视觉路网与车辆重建

底图 `frontend/public/maps/haut-visual.svg` 以用户提供的 CARLA 俯视画面为视觉依据，人工语义描摹连续道路边界、岛区、停车位、斑马线、方向箭头和简化建筑，不再使用碎片化车道多边形拼接 HAUT 底图。生成脚本为 `scripts/build_haut_basemap.py`，可直接重建 SVG。原始截图不被修改。

配准采用原图 2048×719 坐标：`u = 14.8 X + 1027`，`v = 14.8 Y + 366.8`。参考实际 CARLA 上方直道中心 y=-13.119/-8.901，下方直道 y≈7.6/11.8；位置与航向选点仍返回 CARLA 世界米制坐标。此图是从透视截图描摹并按道路中心校准的可视化底图，不作为碰撞判定或测量真值。其他地图继续采用各自原生 CARLA 几何，不套用 HAUT 图像。

“复位”保持现有 actor，导航返回保存起点。“重置”清除当前世界中的车辆、行人、传感器及行人控制器，然后在保存起点重建场景车辆；保留地图、交通信号、交通标志和 spectator。统一“生成全部车辆”清理并重建本控制台车辆，按编辑区全部对象生成，不清理其他客户端车辆。两种重建均在控制空闲时可执行，生成失败时清理本次已生成车辆，避免残留不完整队伍；不会自动开始行驶。场景页统一生成成功后保存该组起终点。

验证包括 actor 销毁顺序、保留静态设施、任务运行时拒绝重建、生成失败清理，以及批量 API 与保存场景一致性。运行栏移除仿真计时、数据/视频开关；原数据回放和驾驶感知页面功能保留。

## 导航归位回路修复

HAUT 北侧东向车道 road 3 / lane +1 在 x≈23.9 m 处为原生拓扑死端；东侧延伸段 43/-3、253/-2、10/-3、24/-3、55/-2、22/-3、17/+3 的原生方向与画面东向、南下、西向箭头相反。归位规划仅对该已校验走廊使用反向几何读取适配，接上 188/-1 西向出口，再沿原生车道网络绕岛返回。不会全局允许逆行，不修改其他地图；继续检查车道宽度、车身采样角点、端点航向与最大曲率。其他起点原有路由保持不变。

另修复目标紧邻 section 起始边界时的搜索漏检：0.75 m 采样可能从前一段直接跨过目标，新逻辑检查已遍历边与目标的位置关系，避免将可达目标误报为断路。回归用例使用障碍车 2 实际完成位姿 (17.7139,-8.3802,3.636°) 至起点 (-8.06,-8.79,0.8°)。

## 拖动与标线核对

地图区域禁止原生文字选择、图片拖拽，左键按下时阻止默认选择行为；交互仍由 pointer capture 处理。运行总览移除动态通行时间轴卡片，地图占满左侧；各屏幕高度下均使用单行网格。坐标刻度移出图例、比例尺与操作工具所在的预留区域。

按原始俯视图逐项复核：中间窄连接路两处分流箭头均朝北，西侧连接路分别向南/向北；东侧横向通道上方两条车道均向西、下方两条均向东；停车岛旁补全双车道箭头；原图中的直行加转弯箭头保留分支；移除左侧路口原图没有的重复直行箭头与推测虚线。东侧连接路分隔虚线位于两条箭头之间，弯道用连续的虚线路径连接上下道路。仅修改可视化标线，不更改车辆路线与控制逻辑。
